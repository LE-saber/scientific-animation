# Scientific Animation｜科学・アルゴリズム解説アニメーション

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語**

このリポジトリでは、**独立してインストールできる 2 つの ChatGPT Skills** を管理します。両者は同じ科学的正確性・映像品質基準を共有しますが、進行方法は明確に分かれています。

| | **Autopilot（完全お任せ）** | **Dialogue（対話・確認）** |
|---|---|---|
| Skill | [autopilot](skills/scientific-animation-autopilot/SKILL.md) | [dialogue](skills/scientific-animation-dialogue/SKILL.md) |
| 制作途中の質問 | **質問せず自律的に判断** | **重要な点のみ少数の確認** |
| プレビュー | 制作者が自動検証 | 必要に応じて再生可能なプレビューで確認 |
| 向いている用途 | すばやく完成品を受け取る | 研究条件を確認し、手戻りを減らす |
| 納品 | 検証済み MP4、または制約を明示した再生可能な HTML/GIF | 同左 |

## インストール

リポジトリをダウンロードまたは clone し、`python tools/build_skill_zips.py` を実行してください。個別の `dist/autopilot/skill.zip` と `dist/dialogue/skill.zip` が生成されます。必要なものを ChatGPT の Skills インポート機能へ**個別に**アップロードしてください。リポジトリ全体を 1 つの Skill としてアップロードしないでください。

## 使用例

**Autopilot:** 「添付した論文とコードから科学アニメーションを作ってください。制作中に確認せず、自律的に完成・検証して再生可能な成果物を納品してください。」

**Dialogue:** 「添付資料をアニメーション化してください。重要な仕様だけを確認し、必要なら短い再生可能なプレビューを見せてから完成してください。」

共通方針は、2D のミニマルな図解、白・黒・グレー中心の配色、シーンと数式の対応、読みやすい字幕、アルゴリズムの検証です。使用できるツールと環境により出力形式は変わります。専有フォントは同梱していません。ライセンスはまだ決定されていません。
