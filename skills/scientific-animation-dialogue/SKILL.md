# 科研动画制作：交互询问模式

**必须完成实际可播放动画。** 这个 Skill 的“交互”仅限于确实影响结果的需求边界；不要将流程变成无休止的访谈或仅生成创意方案。

## 工作契约

- **允许询问**：必要时少量高价值问题；用户已明确的答案不可重问。使用 `references/dialogue-policy.md` 控制提问数量和时机。
- **不与完整托管模式混用**：不能承诺“全过程绝不问问题”；用户切换为托管时，应直接按托管约束继续，而不是在本模式中假装继续询问。
- **完成判定**：最终回复必须包括实际可播放的成片文件路径/链接。若无法生成 MP4，尝试真正可播放的离线 HTML 动画或 GIF，并清楚标注降级。
- 用户可在关键阶段纠偏，但不需要批准普通技术选择（渲染库、转场、代码组织）。

## 最短可靠工作流

1. **读取输入并建立事实台账。** 阅读本轮附件（PDF、PPT、ZIP、HTML、科研论文、源码）及既有约束，区分最新用户设定与旧演示假设。若问题涉及飞梯底部缓存/AMR，加载 `references/rmfs-case.md`。不要猜无法辨认的手写公式。
2. **判断是否需发问。** 先看 `references/dialogue-policy.md`。只有科学机制存在实质冲突、目标仍不清楚等情况，才用一句简短问题和 2–3 个选项确认。默认场景、配色、字幕、视频格式已在标准中给出，不能反复询问。
3. **先做一段可播放的低成本样片。** 以同一个研究场景贯穿问题、路径/数学变换、行为和结果。提取或重算路径、矩阵和事件，并建立镜头时间线、字幕。可先制作 3–8 秒的关键高风险镜头；如果发现确实会导致返工的分歧，可在这一次展示后请求确认。
4. **进入完整制作。** 优先用可控的代码驱动动画：Motion Canvas / Manim / Remotion / HTML Canvas / SVG / FFmpeg（选当前环境真实可用的）。传入确定性算法数据，再做平滑运动、字幕、旁白及音效；不要让生成式视频模型制造数字、公式或路线。
5. **逐层验证。** 阅读 `references/production-qa.md`，先核验物理/数学/时序，再检查代表帧字幕和画面遮挡，最后用脚本检测实际成片的流、分辨率、时长、完整解码。失败就修正、重新渲染。
6. **交付成片。** 主要文件为 MP4；视请求附上离线互动 HTML、SRT、源工程 ZIP 和简短 QA 报告。使用 `references/delivery.md` 定义“完成”。不要把只有提示词、脚本或截图称为成片。

## 视觉与准确性规范

制作前读取 `references/visual-standard.md`，不可只看标题。主要规则：

- 研究动画应是 **scene-integrated mathematical motion graphics**，以二维正交、少量 2.5D、极简几何和自然缓动解释真实场景；避免传统 PPT、满屏 HUD 或霓虹 AI 风。
- 默认**白、黑、灰**为主，只用少量有固定含义的强调色（如暖橙），不默认深蓝/紫黑。
- **解说字幕必须保留并默认可见**：简中、中文微软雅黑 Bold（授权可用时），1080p 约 42–54px；部分设备标签用华文中宋。不要将“去掉冗余小字”等同于“无字幕”。缺失授权字体时用合法替代并说明。
- 让距离随场景中的路线变化、分配结果从成本矩阵回到机器人、事件时刻从真实动作流入时间轴。当前故事背景的物理细节必须正确，不能让货物凭空出现。
- 若资料不足，明确标“示意”，不要编造实验性能、拟合数字或未实现功能。可向用户确认一次真正重要的假设。

## 配套资源（按需读取/运行）

- `references/dialogue-policy.md`：用户沟通与节省 token 的判断规则。
- `references/visual-standard.md`：此前用户反复修订的美术、字体、字幕和数据可视化规范。
- `references/rmfs-case.md`：飞梯货架可穿行、底部缓存接货、货箱归还、A* / 匈牙利 / 最小费用最大流 / 事件滚动的事实边界；**只在 RMFS 案例读取**。
- `references/production-qa.md`：从科研材料到实际动画，导出、验证、降级技术路线。
- `references/delivery.md`：文件、核验、源工程和完成定义。
- `assets/starter/film.html`：能真实播放的单文件 Canvas 示例工程，带播放/暂停/拖动/字幕；**仅作代码起点，演示数字不能当成用户实验结果**。
- `scripts/qa_media.py`：已渲染视频的完整性与预览帧检测。
- `scripts/package_project.py`：按 SHA-256 校验可复现源码 ZIP，自动排除专有字体和常见敏感文件。

## 运行注意事项

只调用实际具备的工具并真实检查生成文件。若无法生成配音，优先保留带可视字幕的真实动画并在最终报告中注明缺音频。不得声称后台继续制作，也不得虚构不存在的下载链接。
